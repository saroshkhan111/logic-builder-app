Circle Area Calculation (r = 7)

                        
Calculate the area of a circle with radius 7 using $\text{Area} = \pi \times r^2$.

                        
                        


PI = 3.14159
radius = 7
area = PI * (radius ** 2)
print(f"Area: {area:.2f}")

                        

                        
                    


                    
                    

                        

                            Problem 2: Arithmetic
                            student_score.py
                        

                        
Student Score Percentage (425/500)

                        
Compute percentage score for 425 out of 500 total marks.

                        
                        


TOTAL_MARKS = 500
obtained_marks = 425
percentage_score = (obtained_marks / TOTAL_MARKS) * 100
print(f"Percentage: {percentage_score:.2f}%")

                            Problem 4: Financial Math
                            simple_interest.py
                        

                        
Simple Interest Calculation

                        
Compute interest for P=10000, R=5%, T=3 years using $(P \times R \times T)/100$.

                        
                        


principal = 10000
rate = 5
time_years = 3
simple_interest = (principal * rate * time_years) / 100
print("Interest:", simple_interest)

                             Script VS Module
                        


                        

                            

                                1. Script (`.py`)
                                
Executable standalone file meant to run directly.

                            


                            

                                2. Module (`.py`)
                                
Reusable code file imported into other scripts (`import utils`). Keep names concise!

                            


                            

                                3. Notebook (`.ipynb`)
                                
Interactive cell environment. Append `_notebook` or `_tutorial` suffix.
